# solar-atlas

**Открыть: https://albertmatseiko.github.io/solar-atlas/**

Производственный атлас солнечной панели **LONGi Hi-MO X6 Explorer LR5-54HTH-420M** (420 Вт):
129 узлов, 12 ветвей, 9 уровней — от модуля до кварцевого карьера, серебряного рудника,
бокситов и нефти. 190 компаний и юрлиц, 37 стран, 137 источников.

## Что открывать

- `index.html` — интерактивное D3-дерево и страница на каждый узел.
- `atlas.html` — тот же атлас одним файлом (удобно скачать и открыть офлайн).
- `about.html` — методика, уровни достоверности и границы данных.

## Публикация

Сайт статический, внешних зависимостей нет: GitHub Pages → Deploy from a branch → `main` / root.
